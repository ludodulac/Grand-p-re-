# Incidents — index sélectif

Lire cette section seulement lorsqu'un problème ressemble à une classe d'échec déjà rencontrée.

## Routage

- [LONG-RUNNING-AUTONOMY.md](LONG-RUNNING-AUTONOMY.md) — une conversation ou validation semble calculer pendant anormalement longtemps ; préférer des boucles bornées, progrès visibles et timeouts.
- [WRONG-LAYER-FIXES.md](WRONG-LAYER-FIXES.md) — un correctif améliore le symptôme mais risque d'intervenir au mauvais niveau ; retrouver la première frontière où la vérité se perd.

## Règle

Un incident Grand Père contient un **enseignement réutilisable**, pas l'historique exhaustif d'un incident projet. Vérifier le dépôt source pour les faits actuels.
